# 三合、飞星与四化视图

参考仓库：<https://github.com/Renhuai123/ziwei-doushu>，固定提交 `7922285d947b36610e7e31c232d8f1e2a0d0871d`，MIT。

公开仓库的 `generateChart` 共用本命安星底盘；其演示 `ChartBoard.tsx` 只连接三方四正与运限叠层，并未提供三个独立的模式组件。本站保留现有 Python 安星算法，移植公开的 `lib/ziwei/sihua.ts` 规则，增加两个交互视图；不声称逐像素复刻未公开的线上站点。

- 三合：原本命全星盘，点击宫位查看本宫、对宫与两组三合宫。
- 飞星：显示十四主星、辅弼昌曲；选中一宫，以其宫干依次计算禄、权、科、忌对应星曜，并按星曜实际所在宫绘制四条有向关系。化星在本宫时保留自化环，不移动星曜。
- 四化：显示上述十八星及生年四化、宫干自化。可选择生年、大限或流年叠层。点击所选层四化落宫时，按 `findIncomingPalaces` 追溯相应星曜及四化类型的全部宫干来源；同一天干出现于多个宫时全部保留。

十干四化表直接采用上游 `constants.ts`，包括戊干右弼科、庚干太阴科、壬干左辅科。生年四化取命盘农历生年的天干；大限四化取所选大限宫的宫干；流年四化取所选流年 `((year - 4) % 10 + 10) % 10` 的天干。童限没有实际当前大限时显示“尚未进入大限”，不隐式套用第一大限；用户仍可明确选取某个未来大限。

后端计算位于 `src/ziwei/transformations.py`。`generate_chart()` 返回的 `natal_chart.transformations` 包含生年、十二大限、流年、48 条宫干飞化及自化列表。`GET /api/charts/{chart_key}/transformations?year=2027` 以经过出生地/时辰修正的命盘键计算指定流年，年份接受 1800–2200。生产运行仍为纯 Python，不依赖 Node。

前端 `PalaceBoard` 只读取已计算的关系并绘图，不自行安星或推算天干。模式、四化层、大限、流年及选中宫位随现有页面状态保存，可刷新恢复。切换不会创建重复命盘或改变对话关联的命盘键。

现有 v4.0 预生成解读及对话资料仍按原三合口径；两个新视图并未生成对应流派的新解读正文。界面在新模式下显示这一说明。

验证：

1. 原有 2,528 组安星对照基准继续通过，包含上游自身拒绝的 8 组输入的单独记录。
2. `tests/fixtures/upstream-transformations.json.gz` 包含 344 组由未经修改的上游 TypeScript 四化函数生成的参考输出，覆盖十干、男女、早子/丑/午/亥、四种闰月规则、四套亮度表。Python 逐条比较生年、大限、流年、48 条飞化与自化。
3. `scripts/verify_chart_schools.py` 实测十二宫全部飞化方向、四化来因、大限切换、流年修改、刷新恢复、童限，以及桌面/矮屏/手机布局；检查星曜与中央文字没有裁切、页面无横向溢出、无 JavaScript 异常。

运行 Python 验证：`.venv/bin/python -m pytest tests -q`。浏览器验证要求本机服务启动且 Playwright/Chromium 可用。
