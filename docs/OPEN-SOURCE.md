# 本次开源整理

- 删除旧源码备份、废弃的 macOS 虚拟环境和系统缓存。
- 删除个人数据库管理配置，以及写死个人路径、旧服务器、一次性迁移状态的工具。
- 移除未接入当前 API 的旧对话 Runtime，工具协议与提示词继续供现行 ChatRuntime 使用；测试改为验证实际运行路径。
- 删除分发目录内的天纪摘录目录，改从 PostgreSQL 片段生成检索目录。
- 统一公开数据的 SQL 初始化入口，支持固定版本下载、校验、重复导入与失败回滚。
- `source_backup` 随旧备份工具退出新库结构；不对既有数据库执行删表。
- 保留国内区划资源及算法测试参考，二者具有明确运行或验证用途。
- 原始数据导入与付费向量生成分开，NULL 明确表示尚未生成向量。
- 增加 MIT 许可、贡献文档、CI 和源码打包工具。

线上使用的 `.env`、Linux 运行环境和 TLS 证书仍留在本机，通过忽略规则及发布包允许清单排除，避免破坏正在运行的服务。

此工作区没有可读取的 Git 元数据，因此未检查历史提交，也未创建提交或向 GitHub 推送。发布包是当前代码的干净快照。
